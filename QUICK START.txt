YAPLOQ QUICK START
=================

1. Extract the entire download and run YapLoq.exe.
2. Open Services and connect Windows voices or a speech provider.
3. Open Voices, create an alias and use Test voice.
4. Speak from Dashboard. Queue contains waiting and recent speech.
5. Open Streamer.Bot for connection and action export instructions.

Keep the _internal folder beside YapLoq.exe.
Settings, logs and audio are stored in the local data folder.
Use the download icon beside the app version for update checks and patch notes.
Service credentials are encrypted for your Windows user on this computer.
