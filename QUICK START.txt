YAPLOQ PREVIEW QUICK START
=========================

1. Double-click YapLoq-preview.exe.
2. Open Services and select Windows voices to get started without an account,
   or select a provider and follow its connection instructions.
3. Open Voices and create a friendly alias for a voice.
4. Use Test voice to confirm the voice and audio output.
5. Open Integrations for Streamer.bot instructions and payloads.

PREVIEW DATA
------------
Settings, history, logs and generated audio are kept in data-preview beside
this preview. Back up that folder to preserve your preview setup.
Production settings are not imported automatically.

Preview networking uses separate ports. UDP, startup actions and automatic
updates are disabled for this preview to protect your existing setup.

TROUBLESHOOTING
---------------
Keep the entire folder together, including the _internal folder.
If a provider cannot connect, select it in Services and use its connection check.
Logs are stored in data-preview\bridge.log.
