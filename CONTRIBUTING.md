# Contributing to VoxRelay

Thanks for helping improve VoxRelay.

## Before opening an issue

- Search existing issues first.
- Include the VoxRelay version and Windows version.
- Explain what you expected and what actually happened.
- Include relevant log lines, but remove usernames, credentials, and private data.

## Pull requests

1. Fork the repository and create a focused branch.
2. Keep unrelated changes out of the pull request.
3. Add or update tests when behavior changes.
4. Run the test suite before submitting.
5. Explain the user-facing effect of the change.

Never commit AWS keys, settings files, generated audio, logs, caches, or other
users' voice assets. By submitting a contribution, you agree that it may be
distributed under the repository's MIT License.
